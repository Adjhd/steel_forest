# 最终文档

每个 campaign 的最终报告、交付表格放在 `<version>/`，例如 `trial-1/候选报告.md`。版本号与 `outputs/<version>/` 的中间结果一致，报告中的相对链接指向对应批次的输入、预测和审查记录。

报告描述批次的实际终态；预算结束或未获准推荐也会形成说明报告。准备模式和执行失败的批次不生成最终报告，可查看对应的 `status.json`。

- `v20261028.001/无磁钢候选报告.md`、`v20261028.001/无磁钢候选表.csv`。
