## 已检查的接口行为

- 场景短名与完整 ID 读取同一活动定义，注册工具版本与安装版本一致。
- 不完整的钢铁元素范围、不闭合成分、范围外候选和场景固定协议覆盖会报错。
- 无磁力学数值未知使用 `null` 或省略；`"unknown"` 数值和不支持的条件字段在准备阶段报错。高熵缺少工艺文本或 0–700 °C 测试温度也在准备阶段报错。
- 模型调用只载入物性模块，没有载入旧 campaign、假设 agent 或 canonical store。准备阶段不载入预测模块或权重。
- 三场景输出键、单位与注册表对应。HEA 四指标均只报告；模型预测不把实测要求判成达标。
